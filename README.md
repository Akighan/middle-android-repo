# README

## Описание приложения

Приложение демонстрирует работу двух подходов к построению пользовательского интерфейса в Android: **Jetpack Compose** и **Custom View**. Оно позволяет пользователям сравнить реализацию элементов в обоих вариантах.

## Основные функции

1. Экран выбора с двумя кнопками:
   - **Первая кнопка** открывает экран, построенный с помощью **Jetpack Compose**.
   - **Вторая кнопка** открывает экран, построенный с помощью **Custom View**.
2. Оба экрана содержат два элемента, различимые по цвету:
   - Первый элемент – **синий**.
   - Второй элемент – **красный**.
3. Элементы размещены в центре экрана и при появлении раздвигаются к верхней и нижней границе экрана.
4. В **Custom View** элементы дополнительно снабжены надписями:
   - Первый элемент: "CUSTOM VIEW FIRST ELEMENT".
   - Второй элемент: "CUSTOM VIEW SECOND ELEMENT".

## Использование

1. Откройте приложение.
2. Выберите один из вариантов: **Custom View** или **Compose**.
3. Осуществите переход на соответствующий экран.
4. **Возвращение на предыдущий экран не поддерживается**, для смены экрана требуется перезапуск приложения.
